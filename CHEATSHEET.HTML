tmux

Prefix = Ctrl+b (unchanged). “Prefix → c” means press Ctrl+b, release both, then press c. Keys are case-sensitive. Copy-mode keys work only after entering copy mode.

Config defined in your dotfilesDefault standard commandPlugin requires an installed plugin

From a shell

Keys or commandActionSource

These run in a shell, not at the tmux command prompt. Detaching is different from closing a shell or killing a pane.

Your status bar is hidden. The config replaces stock split keys and Prefix → l, so generic tmux cheat sheets can be misleading here. Use Prefix → ? to inspect the active bindings.
